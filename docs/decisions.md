# 决策

## 文档和版本放在同一模块

文稿、表格、演示共享所有者、标题、修订号和版本历史，差别在正文结构。版本不是独立生命周期的另一项业务，而是文档聚合的明细。保存必须同时更新主表和版本表，所以事务放在 `document.Repository`。

## 相同内容不重复生成版本

保存时如果规范化正文、标题都没变，且说明为空，返回当前版本且 `new_version=false`。说明非空时仍然新增版本，便于给同一内容补记一条里程碑。恢复总是新增版本，旧历史保留。

## 分页 0

JSON 数字不能区分“字段省略”和 0。`page`、`page_size` 为 0 时使用默认值；负数、超过 200 和过深的页码返回 400。

## 请求体 8MiB

规范示例的 2MiB 不够承载文档 JSON。项目配置为 8388608，业务校验把规范化正文限制在 1MiB。这是容量调整，不是安全保证。

## 会话 Cookie

浏览器使用 HttpOnly、SameSite=Lax Cookie。响应 JSON 不包含原始令牌。带 `Origin` 的跨站请求会在主机不匹配时被拒绝。登录和注册按 IP 每 10 分钟最多 20 次，键数量有上限。

## 定位参数不进 YAML

`base_dir`、`config_dir`、`data_dir`、`profile` 只来自命令行、环境变量和默认值。YAML 若包含这些键，启动失败，避免配置文件把目录又改一次。

## 四库声明

连接和迁移 SQL 按四种数据库准备。自动化测试只运行 SQLite。文档不把另外三种写成已经兼容。
